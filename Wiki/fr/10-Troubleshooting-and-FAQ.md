# ❓ Dépannage et FAQ

| Symptôme | Solution |
| :--- | :--- |
| **Méthodes 11–20 : `UIPI Rejected`** | L'application cible tourne en Administrateur. Cliquez sur le badge **Utilisateur standard** en haut pour élever V-MacroPlus. |
| **Méthodes 1–10 : `Skipped`** | Le mode Arrière-Plan est actif sans focus sur la cible. Désactivez-le ou cliquez sur `Switch`. |
| **Pico / Arduino absent en COM** | Utilisez un **câble USB de données** (pas uniquement de charge). |
| **Décalage des clics en High-DPI** | Utilisez **`F8`** pour lire les coordonnées physiques Win32 exactes. |

- **Dossier de données :** `%APPDATA%\V-Studio\V-MacroPlus\` (Windows) ou `~/.local/share/V-Studio/V-MacroPlus/` (Linux).
- **Confidentialité :** 100 % hors ligne, aucune télémétrie.
