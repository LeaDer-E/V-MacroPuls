# ❓ Устранение Неполадок и FAQ

| Проблема | Решение |
| :--- | :--- |
| **Методы 11–20: `UIPI Rejected`** | Целевая программа запущена от Администратора. Нажмите значок **Обычный пользователь** вверху для повышения прав. |
| **Методы 1–10: `Skipped`** | Включён фоновый тест без фокуса на целевом окне. Выключите его или нажмите `Switch`. |
| **Pico / Arduino не видно на COM** | Используйте **USB-кабель с передачей данных** (не только зарядный). |
| **Смещение кликов на High-DPI** | Используйте **`F8`** для захвата точных физических координат Win32. |

- **Папка данных:** `%APPDATA%\V-Studio\V-MacroPlus\` (Windows) или `~/.local/share/V-Studio/V-MacroPlus/` (Linux).
- **Приватность:** 100% офлайн, без телеметрии.
