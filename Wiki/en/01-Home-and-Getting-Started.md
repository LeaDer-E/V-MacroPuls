# 🏠 Welcome to the V-MacroPlus v3.9.0 Wiki

**V-MacroPlus** is a low-level keyboard and mouse automation studio for **Windows 10/11** and **Linux**, available in both a native **C++20 / Qt 6** edition and a **Python / PySide6** edition. It unifies hardware scan-code Smart Keys, a 240 FPS live recorder, a multi-tab Auto Presser studio, **22 input injection engines** (foreground, background `HWND`, Ring-0 kernel drivers, and physical USB HID microcontrollers like Raspberry Pi Pico & Arduino Pro Micro), and a 10-language glassmorphic UI.

## First Launch
1. **Portable Windows Build:** Extract the archive and run `V-MacroPlus.exe` directly — no installer required.
2. **Onboarding Overlay:** On first run, choose your preferred language from **10 built-in languages** (with automatic RTL mirroring for Arabic, Persian, and Urdu).
3. **Admin / Standard User Badge:** Located in the top header bar. If your target game or app runs as **Administrator**, click the **Standard User** badge to relaunch V-MacroPlus elevated in one click.

## Main Screens Overview
| Tab | Purpose |
| :--- | :--- |
| **Smart Keys** | Bind any single key, 2–3 key chord, mouse button, or manual trigger to multi-step macros and Python scripts. |
| **Auto Presser** | Run unlimited concurrent keyboard & mouse pressing tabs bound to specific background or foreground windows. |
| **Recordings** | Record live keyboard and mouse actions at up to 240 FPS, edit steps, and convert 1-to-1 into Smart Keys. |
| **Test Lab** | Test any single input method or run a strict 22-method diagnostic sweep against a target app or sandbox. |
| **Settings** | Customize Dark/Light mode, 36 color palettes + custom RGB/Hex, language, drivers, backups, and global hotkeys. |
| **About** | Version info, architecture summary, and developer contact card. |
