# ⚙️ Settings, Themes & Global Hotkeys

The **Settings** page controls appearance, language, default input engine, hardware diagnostics, backups, and global shortcuts with instant in-place updates.

## Appearance & 36 HSL Palettes
- Switch between eye-friendly **Dark Mode** and crisp **Light Mode**.
- Pick from **36 curated color palettes** (3 rows × 12 circular swatches) or open the **Custom Color Picker** for any RGB/Hex accent color.

## 10 Built-In Languages
Switch instantly between Arabic (`ar`), English (`en`), Spanish (`es`), French (`fr`), German (`de`), Turkish (`tr`), Russian (`ru`), Indonesian (`id`), Persian (`fa`), and Urdu (`ur`) with automatic RTL/LTR layout mirroring.

## Full Backup & Restore
Export all settings, Smart Keys, saved recordings, and Python scripts into a single portable `.json` file and restore them anytime.

## Global Hotkeys Reference
| Default Hotkey | Action |
| :--- | :--- |
| **`F9`** | Start / Stop live keyboard & mouse recording. |
| **`F10`** | Play / Stop current recorded macro. |
| **`F11`** | Toggle Smart Keys master switch. |
| **`F6`** | Start / Stop active Auto Presser tab (customizable per tab). |
| **`F7`** | Stop all Auto Presser tabs immediately. |
| **`F8`** | Live cursor coordinate grabber `(X, Y)`. |
| **`Ctrl + Shift + Alt`** | **Emergency Stop:** Immediately halts all macros, recordings, scripts, and tabs. |

## Self-Application Immunity
V-MacroPlus automatically excludes its own PID from window pickers and blocks macros/auto-presser clicks from firing into its own UI (except when explicitly testing in the Test Lab Sandbox).
