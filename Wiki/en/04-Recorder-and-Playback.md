# ⏺️ Mouse & Keyboard Recorder

The **Recordings** page pairs a high-precision live recorder (up to 240 FPS) with a collapsible Saved Recordings Library and an interactive timeline editor.

## Clean Recording with Zero Stop-Click Pollution
- Start and stop with **`F9`** or the red Record button.
- **Stop Immunity:** Clicking the main Stop button, clicking the floating Stop pill, or pressing `F9` is automatically stripped so your stop action never pollutes the recording.
- **Auto-Open Steps:** As soon as recording stops, the step editor opens automatically so you can inspect, edit, or save immediately — supporting **10,000+ steps** smoothly via chunked rendering.

## Capture Filters
Toggle each input source independently before recording:
- **Keyboard** (hardware `key_down` / `key_up`, ignoring OS key-repeat)
- **Mouse Clicks** (all 5 buttons with exact screen coordinates)
- **Mouse Scroll** (4-way vertical & horizontal wheel notches)
- **Mouse Path** (optional cursor movement trail)

## Playback & Repeat Options
| Option | Description |
| :--- | :--- |
| **Playback Speed** | `0.25x` to `10.00x` speed multiplier. |
| **Repeat Mode** | **Once**, **By Count** (`0` = infinite), or **For Duration** (seconds / minutes / hours). |
| **Delay Between Repeats** | Fixed interval or **Random Delay** between `0` and the configured time. |
| **Start Playback After** | Countdown delay (`ms`) before playback starts. |
| **Do Not Activate Window on Stop** | Keeps V-MacroPlus in the background when playback finishes. |
| **Floating Stop Pill Toggle** | Show or hide the always-on-top stop pill during playback. |
| **Shutdown on Finish** | Optionally shuts down the PC when a non-aborted repeat finishes. |

## Saving & 1-to-1 Smart Key Conversion
- Update an edited recording in-place (**Save Changes**) or create a copy (**Save as New**).
- Click **Convert to Smart Key** to copy every step losslessly into the Smart Keys studio.
- Press **`F8`** to live-pick coordinates for any mouse step.
