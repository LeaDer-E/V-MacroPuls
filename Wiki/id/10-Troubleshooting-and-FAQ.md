# ❓ Pemecahan Masalah & FAQ

| Masalah | Solusi |
| :--- | :--- |
| **Metode 11–20: `UIPI Rejected`** | Aplikasi target berjalan sebagai Administrator. Klik lencana **Pengguna Standar** di atas untuk elevasi. |
| **Metode 1–10: `Skipped`** | Tes Latar Belakang aktif saat jendela tidak fokus. Matikan atau klik `Switch`. |
| **Pico / Arduino tidak muncul di COM** | Pastikan menggunakan **kabel data USB** (bukan kabel cas saja). |
| **Klik meleset di layar High-DPI** | Gunakan **`F8`** untuk membaca koordinat fisik Win32 secara langsung. |

- **Folder Data:** `%APPDATA%\V-Studio\V-MacroPlus\` (Windows) atau `~/.local/share/V-Studio/V-MacroPlus/` (Linux).
- **Privasi:** 100% offline, tanpa telemetri.
