# ⚙️ Pengaturan, Tema & Pintasan Global

- **Tampilan:** Mode Gelap ramah mata, Mode Terang, **36 palet warna HSL**, dan pemilih warna kustom RGB/Hex instan.
- **10 Bahasa:** Beralih cepat antar `ar`, `en`, `es`, `fr`, `de`, `tr`, `ru`, `id`, `fa`, `ur`.
- **Cadangan Penuh:** Ekspor/impor seluruh pengaturan, makro, rekaman, dan skrip ke satu file `.json`.
- **Pintasan Global:** `F9` (Rekam), `F10` (Putar), `F11` (Tombol Pintar), `F6` (Tab Auto Presser), `F7` (Hentikan semua tab), `F8` (Tangkap koordinat mouse), **`Ctrl + Shift + Alt`** (Berhenti Darurat).
