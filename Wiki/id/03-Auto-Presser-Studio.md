# ⌨️ Studio Auto Presser Multi-Tab

Jalankan **tab otomatis tanpa batas secara bersamaan**, masing-masing di thread tersendiri dan terikat ke jendela target (`HWND`) berbeda.

- **Tab & Pintasan:** Tambah, gandakan, dan ubah nama tab (`F6` default per tab, `F7` hentikan semua tab).
- **Mode Latar Belakang (`Run in background`):** Mengirim tombol/klik langsung ke `HWND` target tanpa mencuri fokus.
- **36 Tombol Bawaan + Tombol Kustom:** Grid 3×12 (`F1–F12`, `1–=`, `Num1–Num*`) dengan tautan **Makro Pintar (`⚡`)**, interval (`10 ms`–`1 jam`), dan tombol tes langsung.
- **Pengklik Mouse Multi-Titik (5 Tombol & 8 Mode):** Tekan **`F8`** untuk menangkap koordinat dan pilih dari 8 mode (`auto`, `real`, `post`, `post_top`, `post_hittest_chain`, `attach_mouse_state`, `guithread_capture`, `sendinput_abs`).
