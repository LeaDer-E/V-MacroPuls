# ⚡ Tombol Pintar & Makro Kustom

Hubungkan tombol fisik apa pun, kombinasi hingga 3 tombol (`Ctrl + Shift + K`), salah satu dari 5 tombol mouse, gulir roda, atau tombol media ke urutan makro.

## Mode Eksekusi
| Mode | Perilaku | Cara Menghentikan |
| :--- | :--- | :--- |
| **Sekali (`once`)** | Menjalankan semua langkah satu kali. | Otomatis atau `Ctrl + Shift + Alt`. |
| **Tahan untuk Ulang (`repeat_hold`)** | Mengulang selama pemicu ditahan. | Lepas tombol atau **Pintasan Berhenti Wajib**. |
| **Putar Berulang (`toggle_loop`)** | Mulai/hentikan loop dengan satu tekan. | Tekan lagi, **Pintasan Berhenti**, atau Berhenti Darurat. |
| **Manual (Tanpa Tombol)** | Klik **▶** di bilah samping. | Otomatis atau Berhenti Darurat. |

## 9 Jenis Langkah (Tanpa Batas — 10.000+ Langkah)
1. **Tekan / Tahan Tombol** (`key_tap` / `key_hold`)
2. **Tunggu** (`wait`, `1 ms`–`10 mnt`)
3. **Klik Mouse** (`mouse_click`, 5 tombol + tangkap koordinat via **`F8`**)
4. **Gulir Mouse** (`mouse_scroll` 4 arah)
5. **Ketik Teks Unicode** (`type_text`)
6. **Mini-Skrip Python** (`python_script`)
7. **Buka Folder / Aplikasi** (`open_folder`)
8. **Perintah PowerShell** (`powershell`)
9. **Perintah CMD** (`cmd`)

Dilengkapi pengurutan seret-lepas halus (`165 ms`), **Undo/Redo (`Ctrl+Z` / `Ctrl+Y`)**, jeda langkah individual, dan catatan pratinjau instan.
