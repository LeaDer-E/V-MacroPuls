# 🧪 معمل التجربة و22 محرك إدخال (Test Lab)

**معمل التجربة** هو أداتك الذهبية لمعرفة أي محرك إدخال يعمل بأفضل كفاءة مع لعبتك أو برنامجك، سواء في الواجهة الأمامية (Foreground) أو في الخلفية (Background).

## مبدأ الفحص الصارم (`Strict No-Fallback`)
أثناء التشغيل العادي، إذا اخترت محركاً غير مثبت (مثل Interception أو Pico غير متصل) ينتقل البرنامج تلقائياً للبديل الآمن لكي لا يتوقف عملك. أما في **معمل التجربة**، فيتم تعطيل البديل التلقائي تماماً حتى يعطيك الفحص نتيجة صادقة 100% توضح لك المحرك الذي نجح فعلاً على التطبيق المستهدف.

## أوضاع الاختبار الستة في معمل التجربة
| # | الوضع | الوظيفة |
| :--- | :--- | :--- |
| **1** | **تشغيل ماكرو أو اختبار سريع** | يشغّل ماكرو محفوظاً أو اختباراً سريعاً (`W -> Space`) بالمحرك المختار حالياً. |
| **2** | **كتابة نص / قالب متغيرات** | يكتب نصاً أو قالباً ذكياً بالمحرك المختار فقط. |
| **3** | **ضغطة زر واحد** | يختبر زراً واحداً بالمحرك المختار. |
| **4** | **فحص شامل — سكريبت بايثون لكل محرك** | يمر على جميع المحركات وينفّذ سكريبت بايثون مخصصاً بكل محرك على حدة. |
| **5** | **فحص شامل — قالب المتغيرات الذكي** | يكتب سطراً تعريفياً بكل محرك (مثل رقم المحرك واسمه) لتعرف فوراً أي محركات استجاب لها التطبيق. |
| **6** | **فحص شامل — ماكرو محفوظ** | يجرب تنفيذ الماكرو المختار على جميع المحركات بالتتابع. |

## صيغة القوالب الذكية (Smart Variable Templates)
يمكنك كتابة قالب واحد يجمع بين النص والمتغيرات وضغطات الأزرار والانتظار، مثل:
```text
key="Enter" {method_num}: Hello V-MacroPlus worked with {method_id} 

```
- **المتغيرات المتاحة:** `{method_num}`، `{method_num_02}`، `{method_id}`، `{method_name}`، `{category}`، `{target_app}`، `{target_hwnd}`، `{mode}`، `{time}`، `{date}`.
- **أوامر الأزرار والانتظار:** `key="Enter"` (أو `Key="Tab"`، `Key="F1"`، `Key="Space"` — يدعم أكثر من 92 زراً)، `
` (Enter)، `	` (Tab)، و`wait=150` (انتظار بالمللي ثانية).

## جدول الـ 22 محرك إدخال
| الأرقام | الفئة | الآلية التقنية |
| :--- | :--- | :--- |
| **1 – 4** | الواجهة الأمامية الأساسية | `SendInput` (ScanCode / Hybrid / Unicode) و`keybd_event` الكلاسيكي. |
| **5 – 6** | الواجهة المتقدمة | `Stealth Humanized` (توقيت 1000Hz وبدون ExtraInfo) و`8-Byte 6KRO USB HID`. |
| **7 – 8** | درايفرات الكيرنل والهاردوير الداخلي | **Method 7:** Ring-0 Kernel `Interception` (`LLKHF_INJECTED = 0`)، **Method 8:** بورت البوردة `PS/2 0x60/0x64` (`InpOutx64`). |
| **9 – 10** | دفعة ذرية ونظام لينكس | **Method 9:** `INPUT[2]` Atomic Burst، **Method 10:** Linux `/dev/uinput` و`XTest`. |
| **11 – 20** | الخلفية (`Background HWND`) | `PostMessageW`، `SendMessageTimeoutW`، استهداف العنصر الداخلي (`Scintilla`, `Edit`, `RichEditD2DPT`)، `AttachThreadInput + SetKeyboardState`، `GetGUIThreadInfo`، `WM_CHAR Triplet`، `WM_IME_KEYDOWN`، و`SendNotifyMessageW`. |
| **21 – 22** | هاردوير USB HID خارجي | **Method 21:** **Raspberry Pi Pico** (`RP2040`/`RP2350`)، **Method 22:** **Arduino Leonardo / Pro Micro** (`ATmega32U4`). |
