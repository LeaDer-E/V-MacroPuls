# ❓ عیب‌یابی و سوالات متداول

| مشکل | راه‌حل |
| :--- | :--- |
| **روش‌های ۱۱ تا ۲۰ خطای `UIPI Rejected` می‌دهند** | برنامه هدف با دسترسی Administrator اجرا شده است. روی نشان **کاربر عادی** بالا کلیک کنید تا V-MacroPlus با دسترسی مدیر باز شود. |
| **روش‌های ۱ تا ۱۰ `Skipped` می‌شوند** | حالت تست پس‌زمینه روشن و پنجره بدون فوکوس است. آن را خاموش کنید یا `Switch` بزنید. |
| **Pico یا Arduino در COM دیده نمی‌شود** | مطمئن شوید از **کابل دیتای USB** (نه کابل شارژ ساده) استفاده می‌کنید. |
| **جابه‌جایی کلیک در نمایشگر High-DPI** | از کلید **`F8`** برای خواندن مختصات فیزیکی دقیق Win32 استفاده کنید. |

- **پوشه داده‌ها:** `%APPDATA%\V-Studio\V-MacroPlus\` (ویندوز) یا `~/.local/share/V-Studio/V-MacroPlus/` (لینوکس).
- **حریم خصوصی:** ۱۰۰٪ آفلاین و بدون هیچ‌گونه ارسال داده.
